# 演示视频脚本（18–20 分钟）

> 要求：10–30 分钟，实机录制，能看清命令与输出。建议 1080p、OBS 录屏 + 麦克风。
> 录制顺序按下面来，一次录完，出错就重录该段，不要剪辑拼接（评审看重真实性）。

## 0. 录制前准备（5 分钟，不进视频）

```sh
cd xv6-proj6
./scripts/build.sh riscv          # 确认能构建
./scripts/test-usertests.sh riscv # 确认 PASS
```

- 终端字号调到 18–20，深色背景。
- 关闭无关窗口与通知。
- 准备两个终端：左边跑 QEMU，右边放文档/代码（可选）。

## 1. 开场：赛题与完成度（0:00–2:00）

**画面**：幻灯片第 1–3 页。

**口播要点**：

- 我们是国防科技大学"吉人自有天相"队，赛题 proj6：xv6 网络和动态链接。
- 基线是 2026 北航扩展版（VFS + HAL，三文件系统、双平台）。
- 一句话说清做了什么：网络从驱动到 socket 全栈自研；动态链接从 `exec` 的 `PT_INTERP` 到用户态 `ld.so` 全链路自研。
- 双平台：RISC-V 全功能；LoongArch 网络已通，动态链接还有一处未完成（第 13 分钟会讲）。

## 2. 架构（2:00–5:00）

**画面**：幻灯片第 4–7 页，配合 `docs/proj6/设计方案.md` 第 3 节的图。

**口播要点**：

- `netdev` 对齐 `blockdev`：协议栈零架构代码，平台差异只在 `transmit` 实现。
- 为什么这么做：新增代码集中在少数文件，既有文件只改十几行。
- 环回为什么走队列：同步递归会在持有 tcb 锁时重入，直接死锁（后面会讲这个 bug）。

## 3. 网络演示（5:00–10:00）

**画面**：左侧终端跑 QEMU，右侧留白放大输出。

```sh
./scripts/run.sh riscv
```

**演示顺序**：

1. 开机自检：念出 `arp: 10.0.2.2 is-at ...` 和 `ping: 10.0.2.2 seq=1 ok rtt=...`，解释这是"驱动 + ARP + IP + ICMP"一条链。
2. `udptest`：`recv 13 bytes from 10.0.2.15:7777 [hello-xv6-udp]`，说明是内核环回。
3. `tcptest`：`server got [ping]` / `client got [pong]`，说明三次握手 + 双向数据。
4. 切一张幻灯片讲 TCP 是"停等发送"：一次一段、等 ACK，吞吐不是强项，取舍写在文档里。

## 4. 动态链接演示（10:00–14:00）

**画面**：同一终端。

```sh
dltest
dynhello
```

1. `dltest`：用户态自己读 ELF、映射、重定位、调用 `add/mul/fib`。
2. `dynhello`：`ld.so: loaded libmath.so at 0x15000` + `add(2,3)=5`，说明 `exec` 的 `PT_INTERP`、auxv、`JUMP_SLOT` 都通了。
3. 打开 `src/user/ldstub.c`，快速指三段：读 `DT_NEEDED`、应用 `RELATIVE`、回填 `GOT`。

## 5. 双平台（14:00–16:00）

```sh
./scripts/build.sh loongarch
./scripts/run.sh loongarch
```

演示：开机 `net: first frame` → `arp` → `ping`，再跑 `udptest`、`tcptest`。

**如实说明**：`dynhello` 在 LoongArch 上卡在解释器进程的 `read`，已定位到"同顺序读文件在普通进程正常、在解释器进程挂住"，下一步查 `copyout` 对 `0x30000000` 段的处理。这一段不要回避，评委会追问。
