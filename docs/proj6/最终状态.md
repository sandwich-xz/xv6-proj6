## 7. Linux 兼容层（对应赛题的国赛测例要求）

赛题要求支持 iperf/netperf/libctest/libcbench，这些是预编译的 Linux 静态二进制。为此实现了 ABI 兼容层：

| 能力 | 状态 | 证据 |
| --- | --- | --- |
| musl 静态程序 | 通过 | 8.9 KB hello 打印 normal |
| busybox 基础 applet | 通过 | `echo` / `uname -a` / `cat` |
| ELF 加载（非页对齐 LOAD） | 通过 | glibc 静态程序可加载 |
| Linux 栈布局（argc/argv/envp/auxv） | 通过 | glibc 跑过 `_dl_aux_init` |
| 40 个 Linux 系统调用 | 已实现 | 见《Linux 兼容层进展.md》 |
| busybox ash 执行脚本 | **未完成** | ash 静默，已排除多条假设 |

修掉的关键根因：FPU 未开启（`scause=0x2` 非法指令）、`loadseg` 页对齐假设、`fork` 未继承 `is_linux`、`fstat` 语义、系统调用号段冲突。

完整记录见 `docs/proj6/Linux兼容层进展.md`。
