## 3. 已知短板（如实）

1. **LoongArch 磁盘 I/O 慢**：virtio-blk 完成中断未接，每次块读等看门狗。功能正确，仅慢。修复方向：接中断或缩短看门狗周期。
2. **TCP 是停等发送**：吞吐 2.3 MB/s，滑动窗口可再提升。
3. **测例接口未确认**：iperf/netperf/libctest/libcbench 未拿到，`select`/`getsockopt` 是否需要补未知。
